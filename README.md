# 🎃 Halloween Visitor Analysis & Forecasting Dashboard

## 📊 Project Overview

The **Halloween Visitor Analysis & Forecasting Dashboard** is an interactive Tableau Business Intelligence project designed to analyze visitor patterns during Halloween events.

The dashboard analyzes visitor traffic across different **years and time periods**, identifies peak visitor periods, compares yearly visitor performance, and provides **future visitor forecasting** based on historical trends.

The project transforms visitor data into interactive visualizations that can help understand visitor behavior and support event planning.

---

## 🎯 Project Objectives

- Analyze visitor traffic across different time periods.
- Identify the peak visitor year.
- Identify the peak visiting time.
- Compare visitor counts across different years.
- Analyze visitor strength by year and time.
- Identify historical visitor trends.
- Forecast future visitor numbers.
- Build an interactive and visually appealing Tableau dashboard.

## 📌 Dashboard Highlights

### 👥 Total Visitors

The dashboard displays a total of **4,147 visitors** in the time-based visitor analysis.

### 📅 Peak Year

**2011** recorded the highest yearly visitor count shown in the dashboard, with approximately **2,843 visitors**.

### ⏰ Peak Time

The highest visitor activity in the time-based analysis occurs at approximately **8:15 PM**, reaching **4,147 visitors**.

## 📈 Visitor Pattern by Time

The dashboard analyzes visitor activity throughout the evening.

| Time | Visitors |

| 6:00 PM | 33 |
